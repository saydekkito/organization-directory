# Organization Directory

Консольное приложение для ведения справочника контактных данных организаций (задание #12 из https://gist.github.com/vlabor54/b5e1a11ac05c825282b2).

## Возможности

- Просмотр списка организаций.
- Поиск по названию, ИНН, e-mail и телефонам.
- Добавление, редактирование и удаление записей.
- Сортировка организаций по названию, ИНН и e-mail.
- Импорт данных из XML-файлов.
- Экспорт данных в XML.
- Проверка корректности вводимых данных.

## Структура проекта

```text
OrganizationDirectory/
├── Models/          # Модели данных
├── Data/            # Работа с базой данных
├── Repositories/    # Доступ к данным
├── Services/        # Бизнес-логика и XML
└── Program.cs       # Точка входа и консольный интерфейс
```

## Запуск

1. Откройте решение `organization-directory.sln` в JetBrains Rider или Visual Studio.
2. Восстановите NuGet-пакеты.
3. Соберите проект.
4. Запустите приложение.

При первом запуске SQLite автоматически создаст базу данных `organization_directory.db`.

## Формат обмена данными

Импорт и экспорт выполняются с использованием XML. При импорте идентификаторы записей назначаются базой данных автоматически.
